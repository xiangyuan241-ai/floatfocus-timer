macOS · Windows · Electron

一个悬浮于所有窗口之上的专注计时器 — 透明、可拖拽、 不需要时不打扰。

架构

让它“漂起来”的四个关键参数

大部分“魔法”都在 BrowserWindow 的配置上。渲染进程只是一个很小的网页。

BrowserWindow 参数 main.js

这几个参数组合起来，把一个普通 Electron 窗口变成了无边框的悬浮控件。

frame
false — 干掉标题栏与窗口装饰
transparent
true — 使 CSS 中的 RGBA 生效
alwaysOnTop
true + 'screen-saver' 层级
resizable
false — 固定尺寸
skipTaskbar
true — 不出现在 Dock / 任务栏
hasShadow
false — 阴影会暴露透明的边缘
setIgnoreMouseEvents
实现点击穿透，配合 {forward: true}

详解

三个值得理解的点

① 悬浮窗口

组合 transparent + frame:false + alwaysOnTop 得到一个无装饰的 RGBA 画布，始终置顶；'screen-saver' 层级让它在全屏应用之上也可见。

win.setAlwaysOnTop(true,
  'screen-saver');
win.setVisibleOnAllWorkspaces(
  true,
  { visibleOnFullScreen: true });

② 拖拽区域

卡片设 -webkit-app-region: drag，按钮用 no-drag 反选。不需要任何 JS 拖拽代码。

.card {
  -webkit-app-region: drag;
}
.controls {
  -webkit-app-region: no-drag;
}

③ 穿透中“解锁”

{forward: true} 下，鼠标事件被忽略，但渲染进程仍能收到 mouseenter。我们用它在“解锁”区域临时反转 ignore。

win.setIgnoreMouseEvents(
  enabled,
  { forward: true }
);
后续

MVP 之后

按“价值÷成本”大致排序的下一步。

01

边缘吸附

磁吸到屏幕四个角 + 记住多屏位置。主进程用 screen.getDisplayMatching 约 50 行代码。

02

番茄钟套餐

自动衔接专注 / 短休 / 长休，并记录数据。只需在渲染层写状态机，右键菜单暴露入口。

03

系统托盘图标

隐藏计时器后仍可从托盘控制。Tray + 复用同一个菜单模板。

04

快捷键自定义

重绑 ⌘⇧T，以及为开始 / 暂停 / +5min 加热键。设置用 electron-store 持久化。

05

主题预设

深色玻璃 · 透明 · 不透明 · 色调。设置面板里实时预览。

06

自动更新与签名

用 Developer ID 签 mac 应用，Windows 走 NSIS，通过 electron-updater 发布。

07

勿扰模式联动

计时中自动开启系统 DND（mac 调 shortcuts CLI；win 改注心助手注册表）。

08

会话记录与洞察

本地 SQLite 存专注记录，周结在顶部弹出。不上传任何数据。

09

多设备同步

可选 iCloud / KV 同步预设与主题。端到端加密、默认关闭。
